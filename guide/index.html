ClickFix First Aid

Fake "I am not a robot" pages are stealing accounts. This stops them.

A ClickFix page pretends to be a CAPTCHA, secretly copies a command, and tells you to press Win+R, paste and press Enter. That one paste installs malware that steals your logins. ClickFix First Aid blocks the trick, checks whether your PC already fell for it, and walks you through recovery.

Stop it

Browser extension

For Chrome and Edge. When a page tries to put an attack command on your clipboard, it swaps it for a harmless message and shows a clear warning. Installers copied by a page are paused until you choose Copy anyway.

Check it

PC check

A read-only Windows script that looks at your Run box, File Explorer and PowerShell history, new programs and startup items for signs of an attack.

Fix it

Recovery guide

The exact steps, in the right order, to cut off stolen sign-ins from your phone and clean your PC.

Install the browser extension

  1. Download clickfix-first-aid-extension-v{{VERSION}}.zip from the latest release and unzip it.
  2. Open chrome://extensions (or edge://extensions) and switch on Developer mode.
  3. Click Load unpacked and choose the unzipped folder.
  4. Open the safe demo and tick the box. You should see a red warning.

Check your Windows PC

  1. Download Check-ClickFix.ps1 from the latest release.
  2. Right-click the file and choose Run with PowerShell.
  3. Read the result. It only reads your PC. It changes nothing and sends nothing anywhere.

Never run this, or anything else, by pasting a command a website gave you. That is exactly the trick this project protects you from.

Optional: turn off Win+R

If you never use the Win+R shortcut, Protect-RunDialog.ps1 turns off Win+R and Win+X for your account, so trap instructions simply do nothing. Run it the same way and pick option 1. Pick option 2 to undo it.

Privacy

  • The extension has no network access and sends nothing anywhere. Its only permission besides reading pages is local storage, for its own counters.
  • The scripts are read-only, except the Win+R switch, which changes one setting for your user and can be undone.
  • Everything is open source, so anyone can check this.
