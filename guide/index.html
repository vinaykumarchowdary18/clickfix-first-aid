Stop fake “I’m not a robot” pages before you paste.

These pages secretly copy a command and tell you to press Win+R, paste and press Enter. That one paste installs malware that steals your logins. ClickFix First Aid swaps the command for a harmless message, so the paste does nothing.

Installers wait for one click

            
Genuine install commands look like attacks. When a site’s copy button copies one, it is paused until you choose Copy anyway or allow that site. Commands you select and copy yourself are never paused.

          

          

        

        

          

            
Check a command before you run it

            
Paste anything a site asked you to run into the extension. It is only read, never run, and it stays on your computer. The popup also counts what it blocked and paused.

Compared with six other anti-ClickFix extensions
Each with its default settings, same test

        

          
Fake verification pages
ClickFix First Aid was the only one to stop all 25 attacks.

          
Ways a page can copy
The only one to cover all five.

          
No instructions on the page
Two extensions stopped more than we did, 22 and 21 of 25. Rules for the five commands we missed are planned for the next version.

          
Warnings only
Three of the six show a warning but leave the attack command on the clipboard, so a visitor who pastes anyway still runs it.

        

        

          
“Stopped” means the attack never reached the clipboard. For ClickFix First Aid, 12 of the 20 commands on pages without instructions were blocked and 8 were paused until the user confirmed. The technical report describes the method and every tool tested.

It watches your clipboard, not you

        
The extension needs to see what pages copy. Everything it learns stays in your browser, and anyone can read the code to check.

      

      

        
Permissions
Reads pages to spot trap instructions and stores its own settings. No other permissions.

        
Internet access
None. The extension’s own pages are blocked from making network requests.

        
Kept on your computer
Counters, the last 20 warnings with a short preview (links broken), your settings and the sites you allowed. Clear it any time.

        
Sent anywhere
Nothing. No account, no analytics, no tracking.

        
Source code
Open source under the MIT license. Read the privacy policy.
